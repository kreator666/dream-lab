# Prop Firm 冒险岛 — UI 设计稿与视觉规范

> 风格：弹弹堂式 Q 版卡通，吉祥物为熊猫岛主。  
> 阶段：MVP（阶段 1–3），先用 AI 生成 + SVG/占位图，后期精修。

---

## 1. 设计系统

### 1.1 品牌色板

| Token | Hex | 用途 |
|-------|-----|------|
| `--color-sky` | `#4ECDC4` | 主色，天空/按钮/高亮 |
| `--color-lemon` | `#FFE66D` | 辅助色，金币/徽章/CTA |
| `--color-peach` | `#FF6B6B` | 强调色，危险/删除/爱心/重要提示 |
| `--color-grass` | `#95E1D3` | 成功/通过/进度完成态 |
| `--color-cream` | `#FFFDF7` | 页面背景，暖白 |
| `--color-chocolate` | `#5D4037` | 深色描边、正文、阴影底色 |
| `--color-cloud` | `#F7F9FC` | 卡片底色、次级背景 |
| `--color-night` | `#2C3E50` | 页脚、深色区块 |

### 1.2 渐变

- **Hero 背景**：`linear-gradient(180deg, #A8EDEA 0%, #FFFDF7 100%)`
- **浮岛草地**：`linear-gradient(180deg, #95E1D3 0%, #4ECDC4 100%)`
- **金币按钮**：`linear-gradient(180deg, #FFE66D 0%, #FDBF2E 100%)`，描边 `#5D4037`
- **主按钮**：`linear-gradient(180deg, #4ECDC4 0%, #2BB5AA 100%)`

### 1.3 圆角与描边

- **按钮**：`border-radius: 9999px`（胶囊形），`border: 3px solid #5D4037`
- **卡片**：`border-radius: 24px`，`border: 2px solid #5D4037`，底部阴影 `0 6px 0 #5D4037`
- **头像/徽章**：`border-radius: 9999px`
- **输入框**：`border-radius: 16px`，`border: 2px solid #5D4037`
- **悬浮助手**：`border-radius: 32px`

### 1.4 阴影（手绘感）

统一使用**硬边描边 + 偏移阴影**，不用模糊阴影：

```css
.card {
  box-shadow: 0 6px 0 #5D4037;
  border: 2px solid #5D4037;
}

.btn-primary {
  box-shadow: 0 4px 0 #2A6B65;
  border: 3px solid #5D4037;
}

.btn-primary:active {
  transform: translateY(4px);
  box-shadow: 0 0 0 #2A6B65;
}
```

### 1.5 字体

- **标题字体**：`ZCOOL KuaiLe`（站酷快乐体）或 `Ma Shan Zheng`，fallback `cursive`
- **正文字体**：`Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, `sans-serif`
- **英文/数字**：`Nunito`, `Comic Sans MS`（仅在装饰性数字）
- **字号**：
  - H1 Hero：`48–64px`（移动端 `32–40px`）
  - H2 页面标题：`32px`
  - 卡片标题：`20px`
  - 正文：`16px`
  - 小字/标签：`14px`

### 1.6 间距

- 页面边距：`px-4 md:px-8 lg:px-16`
- 卡片内边距：`p-6`
- 卡片间隙：`gap-4 md:gap-6`
- 区块间距：`py-12 md:py-20`

## 2. 熊猫岛主吉祥物

### 2.1 基础形象

- **物种**：幼年大熊猫，圆滚滚。
- **装扮**：
  - 草帽（柠檬黄 `#FFE66D`，棕色带子 `#5D4037`）
  - 小背包（天空蓝 `#4ECDC4`）
  - 脖子上挂着小地图卷
  - 手里常拿一根小竹笋或金币
- **表情**：豆豆眼 + 腮红，永远笑眯眯，偶尔困惑。
- **姿态**：站立、挥手、趴着、摔倒、举着牌子。

### 2.2 动作/表情库（MVP 必需）

| 编号 | 名称 | 用途 | 描述 |
|------|------|------|------|
| P1 | 挥手欢迎 | 首页 Hero | 站在浮岛上，右手高举，左手拿地图 |
| P2 | 捧金币笑 | 折扣码/联盟返佣 | 双手捧着金币，眼睛笑成弯月 |
| P3 | 挠头困惑 | 404 / 空状态 / 搜索无结果 | 单手挠头，头顶一个问号 |
| P4 | 趴着加载 | 加载中 | 肚皮贴地，四肢摊开，旁边转圈 |
| P5 | 摔倒打滚 | 错误提示 | 四脚朝天，旁边散落金币 |
| P6 | 举牌子 | 公告/提示 | 举着木牌，可用于强调免责声明 |

### 2.3 AI 生成提示词（英文，给 Midjourney / DALL·E / Stable Diffusion）

```
A cute chubby baby panda character, full body, wearing a straw yellow hat and a tiny teal backpack, holding a treasure map scroll, standing on a small floating island with grass and flowers, sky blue gradient background, DDTank / Boomz cartoon game style, thick black outline, soft cell shading, vibrant candy colors, rounded shapes, friendly smile, rosy cheeks, big sparkling eyes, game mascot, high quality, transparent background --niji 6 --style cute
```

> 生成后需要修成透明 PNG，统一尺寸约 `512×512px`，用于 Web 时输出 `1x/2x` 版本。

## 4. 组件风格规范

### 4.1 主按钮（CTA）

```
背景渐变 sky → teal
圆角 pill
3px 深棕描边
底部 4px 深色硬阴影
hover 上移 2px，阴影变浅
active 下移 4px，阴影消失
文字：深棕，粗体，标题字体
```

### 4.2 卡片

```
背景 cream / white
圆角 24px
2px 深棕描边
底部 6px 深棕硬阴影
hover 轻微上移
内容 padding 24px
```

### 4.3 输入框

```
背景 white
圆角 16px
2px 深棕描边
focus: 描边变 sky，无 ring
placeholder 深棕 50% 透明度
```

### 4.4 标签/徽章

```
圆角 pill
小字 14px
描边 1px
常用组合：
- 折扣码：lemon 背景 + 深棕描边
- 难度星：peach 背景 + 星星图标
- 数据平台：cloud 背景 + sky 描边
```

### 4.5 熊猫装饰元素

- 页面空状态：P3 挠头困惑，居中，下面一行提示文案。
- 加载：P4 趴着，下方转圈动画。
- 错误页：P5 摔倒，配「哎呀，迷路了」文案 + 返回首页按钮。

## 5. 响应式断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| Mobile | < 640px | 单列，底部 Tab 导航，熊猫简化为小头像 |
| Tablet | 640–1024px | 双列卡片，路径图垂直排列 |
| Desktop | > 1024px | 多列，大地图，熊猫完整展示 |

## 7. 占位资产清单

MVP 阶段先用以下占位：

1. **熊猫岛主**：用 SVG 简单几何图形拼一个圆滚滚熊猫（黑耳、黑眼圈、白脸、腮红），后续替换为 AI 生成 PNG。
2. **平台 Logo**：用平台首字母 + 彩色圆形徽章代替真实 Logo。
3. **首页背景**：CSS 渐变 + 几朵 SVG 云 + 草地波浪。
4. **教程封面**：纯色背景 + 标题文字 + 小图标。
5. **浮岛/地图元素**：SVG 简单图形（圆形草地 + 小树 + 小旗子）。
