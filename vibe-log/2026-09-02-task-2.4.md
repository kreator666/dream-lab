## 任务说明
实现联盟营销核心玩法：用户使用本站折扣码下单后可登记订单，并凭已通过审核的登记参与抽奖活动；管理员可在后台审核登记、创建抽奖活动并标记中奖者。

## 完成内容
- 新增 `lib/actions/registration.ts`：创建登记、更新状态、删除登记
- 新增 `lib/actions/raffle.ts`：创建/编辑/切换状态/删除抽奖活动，创建参与记录，标记中奖者
- 新增 `/register-code` 折扣码登记页：
  - 登录用户选择平台、填写折扣码、订单截图链接
  - 显示我的登记记录与审核状态
  - 未登录自动跳转 `/login`
- 新增 `/raffles` 抽奖活动列表页，显示进行中和历史活动
- 新增 `/raffles/[id]` 活动详情页：
  - 展示活动信息与奖品
  - 已登录且有已审核登记的用户可参与
  - 显示参与名单与中奖者
- 新增 `/admin/registrations` 后台登记管理：
  - 列表展示用户、平台、折扣码、截图、状态
  - 支持通过 / 拒绝 / 删除
- 新增 `/admin/raffles` 后台抽奖管理：
  - 创建活动、切换状态（草稿/进行中/已结束）、删除
- 新增 `/admin/raffles/[id]` 抽奖编辑页：
  - 编辑活动信息
  - 显示参与名单
  - 标记中奖者按钮
- 更新后台侧边栏、首页快速入口、Navbar 加入相关入口
- 修复 Prisma optional relation 导致的 TypeScript nullable 报错
